# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-08-30

### Added

- Strict loopback-only JSON webhook scenarios.
- Owned local service lifecycle and readiness checks.
- Exact ordered delivery with duplicates, stale events, and bounded delays.
- Application-owned JSON state probes.
- JSON, Markdown, and JUnit evidence without request content.
- Passing and deliberately broken end-to-end examples.
- Cross-platform CI, release assets, checksums, and clean-install verification.
