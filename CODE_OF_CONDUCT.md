# Code of Conduct

Be respectful, specific, and constructive. Harassment, discrimination,
personal attacks, threats, and publishing another person's private information
are not acceptable in project spaces.

Maintainers may edit or remove contributions that violate these expectations
and may temporarily or permanently restrict participation. Report conduct
concerns privately using the contact route in the maintainer's GitHub profile;
do not open a public issue containing sensitive details.

Enforcement decisions should consider context, impact, repair, and repeated
behavior, with the goal of keeping participation safe and useful.
